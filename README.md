# Profanity Muter

Profanity Muter is a Chrome extension that mutes spoken profanity on YouTube. Speech is transcribed on your device, nothing is uploaded, and it works offline.

- Install: https://chromewebstore.google.com/detail/oejickocjjdcckcjiabjeakcjkjpabgk
- Source code: https://github.com/profanity-muter/profanity-muter
- Privacy policy: https://profanity-muter.github.io/privacy/
- Feedback: https://profanity-muter.github.io/feedback/

This repository holds the extension's public pages (privacy policy and feedback form).
